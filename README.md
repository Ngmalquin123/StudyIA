Sistema Inteligente de Asistencia Académica mediante IA
Nombre del Proyecto:

StudyIA — Asistente Inteligente para Estudiantes
¿De qué trata?

Es una aplicación web que utiliza Inteligencia Artificial para ayudar a los estudiantes con sus actividades académicas.
El sistema permitiría:

    💬 Hacer preguntas a un asistente de IA.
    📚 Explicar temas difíciles de forma sencilla.
    📝 Generar resúmenes de textos.
    ❓ Crear preguntas de práctica a partir de un tema.
    📊 Registrar el progreso del estudiante.
    🎯 Recomendar temas que debería reforzar.
    🔐 Crear cuentas e iniciar sesión.
